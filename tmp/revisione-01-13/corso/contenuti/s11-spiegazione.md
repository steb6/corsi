# Descrivere le variazioni

| Cambio nel progetto | Risultato previsto |
| --- | --- |
| **L aumenta** | tinta più chiara |
| **L diminuisce** | tinta più scura |
| **S diminuisce** | tinta meno intensa, verso il grigio |
| cambia la tinta | cambia la famiglia del colore |

I valori 0–100 sono un modello descrittivo: non dosi di inchiostro.

???
Nella scheda varia una sola grandezza per volta. S = 0 dà un grigio; L = 0 dà nero. Non confondere saturazione e luminosità.

Esempi: monocromatica per un marchio di lusso o una banca; analoga per un prodotto naturale (gialli e arancioni, o verdi e azzurri); complementare per una squadra, un evento, un cartello che deve farsi vedere.
